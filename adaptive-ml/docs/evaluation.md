# Synthetic evaluation plan

PROPOSED: deterministic normalized contexts with continuous preference targets and
explicit training corrections. Hold evaluation contexts apart from corrections;
compare absolute parameter MAE and RMSE against a constant personal baseline.
Report nearby and unfamiliar contexts separately; test repeated transitions, reset,
bounds, capacity and determinism. No measured results exist in this docs milestone.

Synthetic preferences test software mechanics only. They are not microphone recordings,
user-study results or calibrated audio. They cannot establish speech intelligibility,
hearing benefit or clinical effectiveness. Real evaluation needs contextual corrections
and a working, measured audio path from teammates.
